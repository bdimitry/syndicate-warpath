# Animated battlecruiser

`battlecruiser.png` is a transparent 768 × 256 PNG created with the built-in ImageGen tool, using `public/syndicate-banner.png` as a style reference. It is decorative artwork, not a game screenshot. The original banner is preserved.

Generation prompt:

Create a single isolated raster sprite for animating a spacecraft in this exact reference banner. Reference image is style reference only. Subject: ONE long dark gothic armored battle cruiser matching the flying ships in the upper right of the banner, charcoal metal, intricate pointed hull, sparse warm red running lights, small bright red-orange engine at the rear RIGHT. Ship nose points LEFT, seen from slightly below and side, horizontal silhouette with a subtle diagonal lift. Cinematic realistic dark fantasy military painting matching reference lighting. Transparent background with real alpha. Entire ship visible with small padding, wide landscape canvas tightly framed around ship, about 3:1 proportion. No backdrop, no sky, no rectangle, no logo, no text, no watermark. Not a simple icon: detailed textured ship, recognizably part of this scene. No large exhaust plume.

The generated raster was resized and PNG metadata removed for delivery. No SVG is used. The three CSS flight paths share this asset; the return flight mirrors its direction. Pause and reduced-motion controls apply to every animated layer.
